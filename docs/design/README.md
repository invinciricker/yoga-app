# The design files

- **`mockups.html`**: five screens of the app drawn in HTML: Today, Practice, Lesson, After practice, Studio. This is the target. Open it in a browser (it needs the internet once, for the two fonts). Every colour and size in it matches `src/theme/tokens.ts`.
- **`mockups.jpg`**: a picture of the same page, rendered with the real fonts. Look at this first.
- The rules behind the screens, and the screens that are not drawn: `docs/DESIGN.md`.
- The owner also has an editable copy of these screens as a design canvas in his Claude project ("Yoga with Maria: app screens"). If the canvas and this folder ever differ, this folder is what the builder follows, until the architect updates it.

Text in [square brackets] in the mockups stands for facts only Maria can supply (her name, her class times). Lesson titles and descriptions in the mockups are examples.

These files are protected (see `CLAUDE.md`): the builder does not edit them.
